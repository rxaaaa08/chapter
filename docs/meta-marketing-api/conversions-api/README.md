# Conversions API — Developer Docs (offline copy)

Saved 2026-09-19 from <https://developers.facebook.com/documentation/ads-commerce/conversions-api> using Meta's own "View as Markdown" version of each page. **192 pages.** Folders follow the order of the docs sidebar. The first line of each file names the page it came from.

## Notes on this copy

- **Folder 17 is a separate Meta section.** Meta moved the Conversions API Gateway docs to a section called "Conversions API Gateway and Signals Gateway". The ~60 Gateway pages in `13 Guides` are now one-line "This content has moved" notices, so the real content was saved as its own folder.
- **5 pages were converted from the web page**, because Meta's markdown export returns a server error for them: Overview, Integration Guide, Catalog Integration, Integration Guidance: Predicted Lifetime Value (pLTV), Cloud Migration Process. They match Meta's export format closely (tested at 98% against a page that has both); code blocks just don't carry a language label.
- **AWS EKS Onboarding is blank on Meta's site** (both web page and export), as are three unlisted EKS sub-pages linked from elsewhere. Meta's "Cloud Migration Process" page explains EKS is being retired in favour of AWS ECS Express.
- **Escaped characters were decoded.** Meta's markdown export escapes quotes, apostrophes and `<br>` once too often (e.g. `fbq(&#039;track&#039;)`). Each file was decoded once, which makes it match Meta's own "View as Markdown" page character for character (checked on two pages).
- **Payload Helper** is an interactive form on Meta's site, so only its intro text exists as markdown.
