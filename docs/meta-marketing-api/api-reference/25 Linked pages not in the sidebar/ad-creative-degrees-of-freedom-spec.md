# Ad Creative Degrees Of Freedom Spec

## Reading

Degrees of Freedom spec includes specs of how different ad assets can be modified by Dynamic Creative when optimizing the creative

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `creative_features_spec`[AdCreativeFeaturesSpec](https://developers.facebook.com/docs/marketing-api/reference/ad-creative-features-spec/) | Metadata to specify behavior for individual features. List of features can be found in the [AdCreativeFeaturesSpec](https://developers.facebook.com/docs/marketing-api/reference/ad-creative-features-spec/) page. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
