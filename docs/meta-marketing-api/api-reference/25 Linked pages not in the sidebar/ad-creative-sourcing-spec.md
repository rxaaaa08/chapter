# Ad Creative Sourcing Spec

## Reading

AdCreativeSourcingSpec stores metadata about the ad that can be used for creative optimization. For instance, it may include a product set ID, which can be utilized in the 'add catalog items' creative optimization feature.

### Parameters

This endpoint doesn't have any parameters.
