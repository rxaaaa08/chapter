# Minimum Budget

## Reading

The minimum daily budget value for an ad set in an Auction campaign, given the bid_amount if use manual bid

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `currency`string | The currency these budgets pertain to [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `min_daily_budget_high_freq`int32 | The minimum daily budget for an ad set optimized for high frequency actions like clicks and likes. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `min_daily_budget_imp`int32 | The minimum daily budget for an ad set optimized for impressions. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `min_daily_budget_low_freq`int32 | The minimum daily budget for an ad set optimized for low frequency actions like mobile app installs, offer claims, or canvas app installs. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `min_daily_budget_video_views`int32 | The minimum daily budget for an ad set optimized for video views. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
