# Ads Pixel Stats Result

## Reading

The result of a query of Ads Pixel Stats.

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `aggregation`enum | The aggregation used for the stat. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `data`list<AdsPixelStats> | Field value and number of times the pixel fired with the value [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `start_time`[**](#)datetime | Start time of the hourly aggregated fires in ISO8601 format [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |

## Creating

You can't perform this operation on this endpoint.

## Updating

You can't perform this operation on this endpoint.

## Deleting

You can't perform this operation on this endpoint.
