# Custom Audience Session

## Reading

Data upload session for a Custom Audience

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `end_time`numeric string | Upload end time [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `num_invalid_entries`numeric string | Number of invalid entries in the current session [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `num_matched`numeric string | Number of entries matched in the current session [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `num_received`numeric string | Number of entries received in the current session [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `progress`string | Progress of the session [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `session_id`string | Upload session ID [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `stage`string | Status of the session [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `start_time`numeric string | Upload start time [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
