# Targeting Sentence Line

## Reading

Targeting sentence line is description for target spec

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `id`token with structure: ID | ID of the target sentence line [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `params`[Targeting](https://developers.facebook.com/docs/marketing-api/reference/targeting/) | Target spec after normalization [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `targetingsentencelines`list | Plain language description of the target spec [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |

You can't perform this operation on this endpoint.

## Updating

You can't perform this operation on this endpoint.

## Deleting

You can't perform this operation on this endpoint.
