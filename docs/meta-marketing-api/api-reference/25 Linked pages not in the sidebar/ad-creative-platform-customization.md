# Ad Creative Platform Customization

## Reading

Use this field to customize the media for different Facebook [placements](https://developers.facebook.com/docs/marketing-api/targeting-specs/#placement). Currently you can use this field for customizing images and videos. If you specify a media here, it replaces the media originally defined in the ad creative, when the ad displays in those placements. For example, if you define a media here for the `instagram` key, Facebook uses that media instead of the media defined in the ad creative when showing the ad on Instagram.

### Parameters

This endpoint doesn't have any parameters.
