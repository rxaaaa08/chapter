# Ads Image Crops

## Reading

Image crops specification, in the form of `[[{left},{top}],[{right},{bottom}]]` which you can use in a different ad placement. Facebook crops your image according to your given specification. If you don't provide cropping, we display it using defaults. See [Image Crops](https://developers.facebook.com/docs/marketing-api/image-crops/) for more information.

### Parameters

This endpoint doesn't have any parameters.
