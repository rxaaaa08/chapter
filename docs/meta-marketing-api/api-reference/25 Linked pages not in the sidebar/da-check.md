# DACheck

## Reading

Provides the result of running a Dynamic Ads check.

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `action_uri`string | URI to a page that provides steps to resolve the issue this check detects [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `description`string | Description of this check [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `key`enum | Unique identifier of this check [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `result`enum | The result of running this check [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `title`string | Title of this check [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `user_message`string | The explanation of the result after running this check |

## Creating

You can't perform this operation on this endpoint.

## Updating

You can't perform this operation on this endpoint.

## Deleting

You can't perform this operation on this endpoint.
