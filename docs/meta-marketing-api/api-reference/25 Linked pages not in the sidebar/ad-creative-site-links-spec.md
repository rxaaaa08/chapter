# Ad Creative Site Links Spec

## Reading

AdCreativeSiteLinksSpec

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `is_site_link_sticky`bool | is_site_link_sticky [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `site_link_hash`string | site_link_hash computed during creation time [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `site_link_image_hash`string | Specifies the image hash of the site link. Use either site_link_image_hash or site_link_image_url. When both exist, site_link_image_url will be prioritized. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `site_link_image_url`string | Specifies the image url of the site link. Use either site_link_image_hash or site_link_image_url. When both exist, site_link_image_url will be prioritized. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `site_link_title`string | Specifies the display label of the site link [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `site_link_url`string | Specifies the url of the site link [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
