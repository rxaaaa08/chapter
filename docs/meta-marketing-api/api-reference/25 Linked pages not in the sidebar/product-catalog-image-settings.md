# Product Catalog Image Settings

## Reading

Image transformation settings object to customize how items from the catalog would look like in different dynamic ad formats.

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `carousel_ad`[ProductCatalogImageSettingsOperation](https://developers.facebook.com/docs/marketing-api/reference/product-catalog-image-settings-operation/) | Dynamic Ad display settings that would be applied to carousel ads. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `single_ad`[ProductCatalogImageSettingsOperation](https://developers.facebook.com/docs/marketing-api/reference/product-catalog-image-settings-operation/) | Dynamic Ad display settings that would be applied to single item ads. [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |

## Creating

You can't perform this operation on this endpoint.

## Updating

You can't perform this operation on this endpoint.

## Deleting

You can't perform this operation on this endpoint.
